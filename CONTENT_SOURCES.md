## Local presentation rules

- Covers are shown with `object-contain` in a shared aspect-ratio area, so no
  artwork is cropped.
- Titles are displayed exactly as published, with trailing spaces trimmed.
- All product data lives in `src/content/products.ts`; About, community, and
  contact data live in `src/content/site.ts`.
- The root page is a single-page experience. Product images, titles, and
  "View details" buttons open a native `<dialog>` with the same verified data
  used by `/products/<slug>`.
- Every product keeps its internal route at `/products/<slug>` for direct links
  and as a fallback for no-JavaScript browsing.
- Product detail routes show only verified data: category, exact title, current
  price, and, for the bundle only, the public description. The six resources
  omit a description because none is published.
- The external store link is labelled "View on Current Store" and points to the
  verified source URL, both in the dialog and on product detail routes.
- Unlisted product slugs render the branded not-found page. Next.js may send a
  `200` for a streamed fallback and adds `noindex`; cached repeat requests return
  `404`.
